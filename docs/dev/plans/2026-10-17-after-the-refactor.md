- **O1. The admin bypass.** A required check means little while the admin role bypasses at all times, which is what `--admin` uses. _Recommended:_ keep the bypass for emergencies, and do not merge with `--admin` while a required check is pending or failing. _Otherwise:_ change the bypass mode so it no longer covers the required checks, or drop the `update` rule so a normal merge works. [Task 2]
- **O2. #102.** _Recommended:_ a file that refuses every enabled rule is not reloaded, because that cannot silence a pager. _Otherwise:_ keep ruling 7 as amended, and the typo silences everything. [Task 3]
- **O3. #101.** _Recommended:_ (a), the pages, because it cannot join two different rules. Matching rules by content can join two rules that differ, which is the direction that loses an alert. _Otherwise:_ (b), with matching on every field a match reads. [Task 4]
- **O4. #105.** _Recommended:_ remove both Markdown templates, since the forms accept `type:`. [Task 6]
